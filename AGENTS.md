# Shell Shock Campaign Rules

1. Read the canonical GDD and the Drive document CAMPAIGN_ETIQUETTE before mutation. Preserve source reference projects; do not copy or alter other repositories without attribution and deliberate review.
2. Stage code and campaigns in Git first. Record exact source revision, allowed paths, expected outcome, validation and artifacts.
3. Separate authoritative deterministic simulation from Three.js rendering. Hull, turret, view, and ballistic shot are independently tracked. Alpha's designation MUST NOT become the precise firing vector.
4. Preserve crew ownership: Beta aims and fires, Gamma loads, Delta drives, Silver observes. Crew sight and commander sight can differ.
5. Never conflate commit, passing build, running browser, deployment, or human acceptance. Provide receipts with exact evidence.
6. Existing art is replaceable; hull, turret, and barrel visuals must correspond to actual simulation orientation, even with placeholders.
7. Keep changes scoped. Use single-entry-point scripts and isolated execution for remote machines. Never commandeer a Phone Hands control session.
8. Do not claim operational historical accuracy for a fictional Heavy Sherman. Normandy bocage combat is inspired by historical tactics, not a reenactment.
